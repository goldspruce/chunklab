Quote Snapping vs. Entailment

The Two-Gate Attribution Gauntlet in Sanity Engine & ScholarQA Verification
Core Synthesis: Attribution Veracity requires passing two sequential gates:
$$\text{Attribution Veracity} = \underbrace{\text{Gate 1: Quote Snapping}}_{\text{Physical Grounding on Disk}} \ \land \ \underbrace{\text{Gate 2: Entailment}}_{\text{Logical & Epistemic Support}}$$

1. Executive Comparison

Core Question "Did the human author actually write these exact words in the literature?" "Does this quote actually prove or logically support the model's claim?"

2. The Four Quadrants of Scientific Attribution

Quadrant I: Verifiable Truth (Gate 1 ✅, Gate 2 ✅)

Status: Grounded & Deductively Sound.
Example: Sanity Engine $S_2$ & $S_3$ on Question 2. Quote ($\frac{1}{2} m v_x^2 = \frac{1}{2} k_B T$) exists verbatim on page 2 of Berg (1993) and logically entails that thermal velocity is independent of fluid viscosity.

Quadrant II: Citation Bluffing (Gate 1 ✅, Gate 2 ❌)

Status: Attribution Poisoning.
Example: Frontier Long-Context ($S_{\text{cached}}$) on Question 3. Retrieves a real 30-word sentence from Page 848 regarding adiabatic sound velocity, but attaches it to a claim about acoustic boundary impedance reflection. 100% genuine text, 100% citation bluff.

Quadrant III: Plausible Hallucination (Gate 1 ❌, Gate 2 ✅)

Status: Fabricated Source.
Example: Unassisted Frontier LLM ($S_0$) generating quotes from memory: "Berg writes: 'Equipartition dictates that viscous drag does not alter instantaneous kinetic velocity.'" Entailment is logically sound, but Berg never wrote that sentence!

Quadrant IV: Total Delusion (Gate 1 ❌, Gate 2 ❌)

Status: Synthetic Nonsense.
Example: Fabricated quote from a non-existent paper asserting an unphysical conservation violation.

3. Gate 1 Mechanics: Quote Snapping

In real-world scientific literature, textbook scans and digitized papers contain OCR anomalies: line-break hyphenation (ther- \n mal motion), curly quotes (“...”), non-breaking spaces, and ellipsis joins (...). A naive exact string match falsely rejects real citations.

Quote Snapping implements a 4-stage algorithmic gauntlet in engine.py:

  1. Ellipsis Clause Splitting: Breaks compound quotes separated by ... into independent sub-clauses (≥ 3 words) and verifies each independently.
  2. OCR Normalization: Strips line-break hyphens, quotes, and punctuation (clean_for_quote_match).
  3. Exact Substring Matching: Evaluates clean quote against clean corpus passages.
  4. Fuzzy Shingle Snapping: Computes sliding 6-word shingles. If ≥ 50% of shingles hit a continuous chunk in the corpus, it snaps the candidate to its exact physical byte coordinates on disk.

4. Gate 2 Mechanics: Entailment

Gate 2 implements an adversarial Natural Language Inference (NLI) referee using an isolated, closed-world prompt at temperature $T=0.0$:

ENTAIL_SYS = (
    "Decide whether the QUOTE supports the CLAIM. "
    "Use only the quote. Answer supports / partly / not / unclear with a one-sentence reason."
)

class Entail(BaseModel):
    label: Literal["supports", "partly", "not", "unclear"] = "unclear"
    why: str = ""

Sequential Execution Rule: Gate 2 runs only if Gate 1 returned verified. There is no mathematical or logical purpose in evaluating whether a fabricated quote entails a claim, because the quote itself is synthetic!

d["quote_status"] = verify_quote(i.quote, p["text"], retriever.chunks) if p else "bad_passage_id"
d["auto_entail"] = None
if auto_entail and d["quote_status"] == "verified":
    d["auto_entail"] = Entail.model_validate(critic.json(
        ENTAIL_SYS, f"CLAIM: {i.claim}\nQUOTE: {i.quote}", Entail, 0.0)).model_dump()

5. Key Takeaways

  • Quote Snapping ensures you are reading real words written by the actual author on disk.
  • Entailment ensures those words actually prove the specific claim being asserted.
  • Checking only Gate 1 allows Citation Bluffing ($S_{\text{cached}}$ failure mode).
  • Checking only Gate 2 allows Hallucinated Citations ($S_0$ failure mode).
  • Both gates are non-negotiable for zero-hallucination scientific AI.
