Underlying Engines Explained in Simple Terms

Demystifying Quote Snapping vs. Entailment Verification
Context: In the attribution comparison, the row "Underlying Engine" defines the computational tools used to verify scientific citations:

• Quote Snapping: Deterministic Python / RegEx, 6-word shingle hashing (≥ 50%)
• Entailment: Adversarial NLI LLM Critic (T=0.0), Closed-World Prompt

Part 1: Quote Snapping Engine Explained

1. Deterministic Python

This is standard, non-AI computer code—like a calculator or basic word processor search. It doesn't use neural networks, so it has zero chance of hallucinating. If you run it 10,000 times, it reads the exact textbook file on disk and gives the exact same result every time.

Analogy: A digital barcode scanner

2. RegEx (Regular Expressions)

A text-cleanup tool. Scanned book PDFs often split words with hyphens across lines (ther- \n mal) or use fancy curly quotes (“ ”). RegEx acts like a digital squeegee to strip formatting noise and fix broken hyphenated words so a real quote isn't rejected over a typo.

Analogy: A squeegee cleaning dirt off a window

3. 6-Word Shingle Hashing (≥ 50%)

Like overlapping shingles on a house roof, the quote is sliced into overlapping 6-word windows (Words 1–6, Words 2–7, Words 3–8). If at least 50% of these 6-word blocks match in a single continuous chunk in the book on disk, the system confirms the passage is authentic and "snaps" to its physical byte coordinates.

Analogy: Fingerprint matching that tolerates minor smudges

Part 2: Entailment Engine Explained

1. Adversarial

Most AI prompts instruct the model to be polite, helpful, and generous. An adversarial critic is explicitly told to be a harsh, skeptical referee looking for any logical leap, exaggeration, or bluff. It will not give the student the benefit of the doubt.

Analogy: A strict DMV inspector or hostile courtroom cross-examiner

2. NLI (Natural Language Inference)

The computer science term for strict deductive logic: "If Quote A is true, does Claim B logically have to be true?" It prevents citation bluffing by verifying that the quote actually proves the claim, rather than just being an impressive-sounding sentence from the same chapter.

Analogy: Deductive logic (Premise ⇒ Conclusion)

3. LLM Critic at Temperature Zero ($T = 0.0$)

Temperature controls creativity in AI. At $T = 0.7$, the AI is creative and unpredictable. At $T = 0.0$, all randomness is shut off. The AI strictly selects the single most probable, mathematically certain word, guaranteeing consistent verdicts.

Analogy: A calibrated digital scale that always reads the exact same weight

4. Closed-World Prompt

Frontier LLMs have memorized vast amounts of science. If the referee used its background knowledge, it might pass an unrelated quote because it already knows the claim is true from memory! The closed-world prompt seals the referee in a box: "You know nothing about the universe except these exact words. If the quote doesn't explicitly prove the claim on its own, you must reject it."

Analogy: A juror instructed by a judge to disregard rumors and evaluate only Exhibit A
